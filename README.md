# Nziza Project

## About
Nziza is a web development project built to provide a simple and user-friendly experience.

## Features
- Easy-to-use interface
- Responsive design
- Modern web technologies

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Tailwind CSS

## Installation

1. Clone this repository.
2. Open the project folder.
3. Navigate to the frontend directory.
4. Install the dependencies:

   `npm install`

5. Start the development server:

   `npm run dev`
